## Informationen

- **Datum** : Ursprüngliches Veröffentlichungsdatum der Cloud Temple-Sicherheitswarnung.
- **Referenz(en)** : CVE-ID, je nach Verfügbarkeit.
- **CVSS** : Basis-CVSS-v3-Score, wie vom Hersteller oder CVE gemeldet, ohne Kontextualisierung. Die Kontextualisierung wird durch die CT-Schweregradangabe ausgedrückt. Wenn die Warnung mehrere Schwachstellen betrifft, werden die minimalen und maximalen CVSS-Scores angegeben.
- **Titel** : Titel der Warnung, mit Herstellerreferenz falls verfügbar.
- **Beschreibung** : Zusammenfassende Beschreibung, mit Link(s) zu detaillierten Informationen.
- **Service(s)** : Potentiell betroffene Cloud Temple-Service(s).
- **Schweregrad** : Schweregradstufe im Kontext der Cloud Temple-Service (für die kritischste Schwachstelle bei mehreren Schwachstellen). Die Ausnutzungskriterien werden im technischen Kontext unserer Cloud-Infrastrukturen und -Services berücksichtigt.

| Stufe | Beschreibung |
|--------|-------------|
| 🔴 **Kritisch** | Schwachstelle mit CVSS 7+, die ein hohes Ausnutzungsrisiko darstellt (hohe Exposition, einfache Ausnutzung). Eine Korrektur oder Minderung in kürzester Zeit wird dringend empfohlen.|
| 🟠 **Wichtig** | Schwachstelle mit CVSS 7+, die kein hohes Ausnutzungsrisiko darstellt (begrenzte Exposition oder Ausnutzungsbeschränkungen) |
| 🟡 **Moderat** | Schwachstelle mit CVSS 4+ |
| 🔵 **Gering** | Schwachstelle mit CVSS unter 4 oder nicht ausnutzbar. |

- **Bearbeitung** : Informationen und Empfehlungen im Kontext der Cloud Temple-Service. ⚠️ zeigt an, dass eine Aktion der Benutzer erforderlich ist, um die Schwachstelle zu beheben. ✅ zeigt an, dass die Bearbeitung der Schwachstelle von Cloud Temple übernommen wird.
