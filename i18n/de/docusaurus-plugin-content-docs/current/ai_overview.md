# KI

Mit den KI-Diensten von Cloud Temple nutzen Sie KI-Modelle auf einer souveränen, in Frankreich gehosteten Infrastruktur. Um eigene Workloads auf NVIDIA-GPUs auszuführen, siehe die GPU-Blades von [Bare Metal](./iaas_bare-metal/concepts.md#gpu), [IaaS VMware](./iaas_vmware/concepts.md#gpu) und [IaaS OpenSource](./iaas_opensource/concepts.md#gpu) sowie die GPU-Worker-Nodes von [PaaS OpenShift](./paas_openshift/concepts.md#gpu).
