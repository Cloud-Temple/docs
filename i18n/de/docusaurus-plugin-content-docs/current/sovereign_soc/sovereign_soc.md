# Übersicht über Sovereign SOC

Das **Sovereign SOC** (Security Operations Center) ist ein rund um die Uhr (24/7) betriebener Managed Service zur Erkennung und Qualifizierung von Sicherheitsvorfällen. Es erfasst und analysiert die Protokolle Ihrer Informationssysteme, unabhängig davon, ob diese in der vertrauenswürdigen Cloud oder anderswo gehostet werden, und kombiniert eine automatisierte Vorqualifizierung durch künstliche Intelligenz mit der Validierung jedes Vorfalls durch französischsprachige Sicherheitsanalysten.

So erhalten Sie qualifizierte Incident-Tickets und eine Nachverfolgung der Behebung, ohne selbst eine Erkennungsplattform betreiben zu müssen.
