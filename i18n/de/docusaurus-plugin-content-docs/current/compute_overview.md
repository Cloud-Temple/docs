# Compute

Die Compute-Dienste von Cloud Temple ermöglichen es Ihnen, virtuelle Maschinen auf einer souveränen und sicheren Infrastruktur bereitzustellen und zu betreiben. Wählen Sie die Technologie, die Ihren Anforderungen entspricht: Multi-Tenant-Cloud-Instanzen, Open-Source-Infrastruktur oder VMware-Virtualisierung.
