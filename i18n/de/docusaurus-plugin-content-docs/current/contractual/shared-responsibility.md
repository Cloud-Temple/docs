# Modell der geteilten Verantwortung

Cloud Temple arbeitet nach einem Modell der **geteilten Verantwortung** zwischen Anbieter und Kunde. Diese RACI-Matrizen (*Responsible, Accountable, Consulted, Informed*) definieren präzise, wer was für jeden Dienst verantwortet.
