# Übersicht über Bastion

Der **Bastion Cloud Temple** ist ein sicherer und verwalteter Dienst, der die Verwaltung Ihrer Infrastrukturen über RDP- oder SSH-Verbindungen vereinfacht.

Über die Cloud Temple-Konsole zugänglich, gewährleistet er eine zentrale Verwaltung, während er Ihre Geräte vor direktem Internetzugriff schützt.

Mit seinem sicherheitsorientierten Ansatz und erweiterten Funktionen wie Infrastructure as Code erfüllt der Bastion die Anforderungen von Cloud-, Hybrid- und On-Premises-Umgebungen.
