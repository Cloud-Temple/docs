# Übersicht über AIOps

Der Dienst **AIOps** von Cloud Temple ist eine Plattform für operative Intelligenz: Er wendet künstliche Intelligenz auf die Überwachung, die Analyse von Störungen und die Automatisierung der Betriebsaufgaben Ihres Informationssystems an. Er unterstützt Ihre Teams wie ein Copilot, ohne sie zu ersetzen.

AIOps ist ein Managed Service. Er wird über die Experten von Cloud Temple gebucht, die mit Ihnen seine Integration in Ihre Umgebung prüfen: Er wird nicht über die Cloud-Temple-Konsole bestellt und hat dort weder eine Ansicht noch eine API.
