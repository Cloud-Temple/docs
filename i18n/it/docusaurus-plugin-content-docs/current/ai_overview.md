# IA

I servizi di intelligenza artificiale di Cloud Temple consentono di utilizzare modelli di IA su un'infrastruttura sovrana ospitata in Francia. Per eseguire i vostri carichi di lavoro su GPU NVIDIA, vedere i blade GPU di [Bare Metal](./iaas_bare-metal/concepts.md#gpu), [IaaS VMware](./iaas_vmware/concepts.md#gpu) e [IaaS OpenSource](./iaas_opensource/concepts.md#gpu), e i worker node GPU di [PaaS OpenShift](./paas_openshift/concepts.md#gpu).
