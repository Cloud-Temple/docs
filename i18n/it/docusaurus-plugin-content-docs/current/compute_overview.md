# Calcolo

I servizi Compute di Cloud Temple consentono di distribuire e gestire macchine virtuali su un'infrastruttura sovrana e sicura. Scegliete la tecnologia più adatta alle vostre esigenze: istanze cloud condivise, infrastruttura open source o virtualizzazione VMware.

    <a href="./public_cloud/vm_instances" class="card-link">Scoprite Istanze VM →</a>
  </div>

    <a href="./iaas_opensource" class="card-link">Scoprite IaaS OpenSource →</a>
  </div>
  <div class="card">
    <h3>IaaS VMware</h3>

    <a href="./iaas_vmware" class="card-link">Scoprite IaaS VMware →</a>
