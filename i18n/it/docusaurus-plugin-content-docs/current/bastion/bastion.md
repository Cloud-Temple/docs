# Panoramica di Bastion

Il **Bastion Cloud Temple** è un servizio sicuro e gestito che semplifica l'amministrazione delle vostre infrastrutture tramite connessioni RDP o SSH.

Accessibile dalla console Cloud Temple, garantisce una gestione centralizzata proteggendo al contempo le vostre apparecchiature da qualsiasi esposizione a Internet.

Grazie al suo approccio orientato alla sicurezza e alle funzionalità avanzate come l'Infrastructure as Code, il Bastion soddisfa le esigenze di ambienti Cloud, ibridi e on-premises.
