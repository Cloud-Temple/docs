## Informazioni

- **Data** : Data di pubblicazione iniziale dell'allerta di sicurezza Cloud Temple.
- **Riferimento(i)** : ID CVE, secondo disponibilità.
- **CVSS** : Punteggio CVSS v3 di base come riportato dall'editore o dal CVE, non contestualizzato. La contestualizzazione è espressa dalla severità CT. Se l'allerta riguarda più vulnerabilità, i punteggi CVSS min e max sono indicati.
- **Titolo** : Titolo dell'allerta, con riferimento editore se disponibile.
- **Descrizione** : Descrizione sintetica, con link a informazioni dettagliate.
- **Servizio(i)** : Servizio(i) Cloud Temple che possono essere interessati.
- **Severità** : Livello di severità nel contesto dei servizi Cloud Temple (per la vulnerabilità più critica in caso di vulnerabilità multiple). I criteri di esplorazione sono presi in considerazione nel contesto tecnico delle nostre infrastrutture e servizi Cloud.

| Livello | Descrizione |
|--------|-------------|
| 🔴 **Critica** | Vulnerabilità CVSS 7+ che presenta un rischio di esplorazione importante (forte esposizione, facilità di esplorazione). Una correzione o mitigazione nel più breve tempo possibile è fortemente raccomandata.|
| 🟠 **Importante** | Vulnerabilità CVSS 7+ che non presenta un rischio di esplorazione importante (esposizione limitata o vincoli di esplorazione) |
| 🟡 **Moderata** | Vulnerabilità CVSS 4+ |
| 🔵 **Bassa** | Vulnerabilità CVSS inferiore a 4, o non esplorabile. |

- **Gestione** : Informazioni e raccomandazioni nel contesto dei servizi Cloud Temple. ⚠️ indica che un'azione degli utenti è necessaria per gestire la vulnerabilità. ✅ indica che la gestione della vulnerabilità è presa in carico da Cloud Temple.
