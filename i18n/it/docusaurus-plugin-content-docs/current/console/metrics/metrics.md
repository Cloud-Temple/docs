# Panoramica di Observability

**Observability** mette a disposizione le metriche della vostra infrastruttura Cloud Temple negli standard di mercato: un proxy Prometheus integrato nella Console, dashboard nell'interfaccia web e l'integrazione con il vostro strumento di visualizzazione, come Grafana.

Il servizio è incluso senza costi aggiuntivi in ogni sottoscrizione Cloud Temple. Cloud Temple fornisce l'origine dati e modelli di dashboard open source; mantenete il vostro strumento di monitoraggio.
