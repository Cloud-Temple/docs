title: Panoramica
---

Il servizio **VM Instances** di Cloud Temple consente il rapido dispiegamento di macchine virtuali su un'infrastruttura condivisa e ad alte prestazioni. Questa offerta combina la flessibilità del cloud pubblico con le garanzie di sicurezza di un cloud sovrano.

Si adatta a tutte le esigenze grazie alle sue diverse classi di servizio — dallo sviluppo economico alla produzione critica — integrandosi nativamente nell'ecosistema Cloud Temple.
