# Panoramica di AIOps

Il servizio **AIOps** di Cloud Temple è una piattaforma di intelligenza operativa: applica l'intelligenza artificiale al monitoraggio, all'analisi degli incidenti e all'automazione delle attività operative del vostro sistema informativo. Affianca i vostri team come un copilota, senza sostituirli.

AIOps è un servizio gestito. Si sottoscrive tramite gli esperti di Cloud Temple, che studiano con voi la sua integrazione nel vostro ambiente: non si ordina dalla Console Cloud Temple e non vi dispone né di una vista né di un'API.
