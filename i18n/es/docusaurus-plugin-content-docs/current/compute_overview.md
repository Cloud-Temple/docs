# Cómputo

Los servicios de Cómputo de Cloud Temple le permiten desplegar y operar máquinas virtuales en una infraestructura soberana y segura. Elija la tecnología que se adapte a sus necesidades: instancias cloud compartidas, infraestructura open source o virtualización VMware.
