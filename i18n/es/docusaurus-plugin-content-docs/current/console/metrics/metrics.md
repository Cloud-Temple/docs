# Visión general de Observability

**Observability** pone a su disposición las métricas de su infraestructura Cloud Temple en los estándares del mercado: un proxy Prometheus integrado en la Consola, paneles en la interfaz web y la integración con su propia herramienta de visualización, como Grafana.

El servicio está incluido sin coste adicional en cualquier suscripción de Cloud Temple. Cloud Temple proporciona la fuente de datos y plantillas de paneles de código abierto; usted conserva su herramienta de supervisión.
