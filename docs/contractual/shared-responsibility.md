# Modèle de responsabilité partagée

Cloud Temple opère selon un modèle de **responsabilité partagée** entre le fournisseur et le client. Ces matrices RACI (*Responsible, Accountable, Consulted, Informed*) définissent précisément qui fait quoi pour chaque service.
