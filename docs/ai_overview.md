# IA

Les services d'intelligence artificielle de Cloud Temple vous permettent d'utiliser des modèles d'IA sur une infrastructure souveraine hébergée en France. Pour exécuter vos propres charges sur des GPU NVIDIA, voir les lames GPU de [Bare Metal](./iaas_bare-metal/concepts.md#gpu), d'[IaaS VMware](./iaas_vmware/concepts.md#gpu) et d'[IaaS OpenSource](./iaas_opensource/concepts.md#gpu), et les worker nodes GPU de [PaaS OpenShift](./paas_openshift/concepts.md#gpu).
