# Vue d'ensemble d'Observability

**Observability** met à disposition les métriques de votre infrastructure Cloud Temple dans les standards du marché : un proxy Prometheus intégré à la Console, des tableaux de bord dans l'interface web et une intégration avec votre propre outil de visualisation, comme Grafana.

Le service est inclus sans surcoût dans toute souscription Cloud Temple. Cloud Temple fournit la source de données et des modèles de tableaux de bord open source ; vous gardez votre outil de supervision.
